# Dataset Curator

Графическое приложение на Python/Tkinter для первичного отбора изображений перед обучением LoRA/SDXL. Работает локально: исходные изображения не загружаются на сторонние серверы; для моделей Hugging Face необходим интернет при первом скачивании, если веса ещё не закэшированы.

## Возможности

- Фильтрация по разрешению (одна или обе стороны).
- Поиск достаточно крупных лиц через MediaPipe BlazeFace.
- Проверка резкости по variance of Laplacian.
- Эстетическая оценка через `aesthetic-predictor` с порогами `selected` и пограничной зоны.
- Поиск near-duplicates по perceptual hash (phash/dhash/whash/ahash), с тестовым режимом без перемещения.
- Необязательные подписи изображений через BLIP и классификация по текстовым категориям через CLIP.
- Отчёт CSV, журнал, прогресс и остановка после текущего изображения.
- Автосохранение параметров, пути к датасету, категорий CLIP, активной темы, размера и положения окна.
- Две темы интерфейса по образцу VK Downloader: светлая и тёмная с синим акцентом.

## Требования

- Windows 10/11 или другая ОС с Python 3.10+ и Tkinter.
- Рекомендуется Python 3.10–3.12 для совместимости AI-зависимостей; сверяйте версии библиотек со своим рабочим PyTorch.
- Установите зависимости командой:

```bat
uv pip install --system -r requirements.txt
```

Если используете виртуальное окружение, активируйте его и выполните `uv pip install -r requirements.txt` без `--system`.

**PyTorch/CUDA устанавливайте отдельно.** Не переустанавливайте рабочую GPU-сборку только ради запуска необязательных моделей BLIP/CLIP.

Если приложение запущено с включённым CLIP или BLIP, но `transformers` не установлен, оно предупредит об этом до начала обработки. Можно отменить запуск и установить зависимость либо согласиться продолжить без AI-функций. Если модель не удастся скачать или загрузить, приложение запишет предупреждение в журнал и продолжит базовую фильтрацию без этой модели. Для установки только AI-зависимостей запустите `install_optional_ai.bat`.

## Запуск

```bat
python dataset_curator_gui.py
```

На Windows также можно запустить `start_dataset_curator.bat`. При необходимости исправьте путь к Python в начале BAT-файла.

1. Выберите исходную папку с изображениями непосредственно в её корне.
2. Настройте вкладки «Фильтры» и «AI-модели».
3. Нажмите **«▶ СТАРТ — обработать изображения»**.
4. На вкладке «Журнал и отчёт» отслеживайте ход работы.

Настройки хранятся рядом со скриптом в `dataset_curator_settings.json`. Параметры сохраняются автоматически после изменения и при закрытии приложения. Этот файл добавлен в `.gitignore` и не предназначен для публикации.

## AI-модели

- **MediaPipe BlazeFace** — поиск лиц; при отсутствии модели приложение может загрузить официальный файл `blaze_face_short_range.tflite`.
- **Aesthetic Predictor** — оценка эстетики; скор зависит от модели и не является объективной оценкой качества.
- **BLIP** — генерация черновых текстовых подписей рядом с выбранными изображениями в формате `.txt`. Можно задать trigger token.
- **CLIP** — сопоставление изображения с заданными текстовыми категориями. CLIP классифицирует, а не генерирует свободные подписи. Совместно с BLIP выбранную категорию можно добавить в caption.

AI-модели необязательны и загружаются только при включении соответствующих функций. Для приватных или чувствительных изображений предпочтительно использовать локально закэшированные веса и заранее отключить сетевой доступ после скачивания.

## Результаты

Приложение создаёт подпапки `selected`, `rejected`, `bed_size`, `blure`, `no_or_small_faces`, `moree_faces` и при поиске дублей `duplicate`. CSV-отчёт `dataset_report.csv` сохраняется в исходной папке.

По умолчанию исходные изображения не удаляются, а результаты фильтрации копируются в соответствующие папки. Очистка выходных папок выключена по умолчанию и требует подтверждения. Для near-duplicates включён безопасный режим без перемещения.

## Важно

Сначала протестируйте настройки на копии небольшого набора. BLIP-caption — черновик, а оценка эстетики, резкости и сходства зависит от типа изображений и заданных порогов. Перед обучением проверьте результаты вручную.


## Обновление

В ZIP-копии проекта запустите `update.bat`: он скачает актуальный архив ветки `main` и обновит файлы программы, не удаляя пользовательские настройки, локальную модель MediaPipe, отчёты и папки датасета. В Git-клоне обновлятор использует `git fetch` и только fast-forward merge; при наличии локальных изменений он сначала предложит отменить обновление или явно разрешить перезапись. Устаревшие файлы в ZIP-копии автоматически не удаляются.

После обновления при необходимости обновите зависимости командой `uv pip install --system -r requirements.txt`. Не запускайте установку PyTorch поверх рабочей CUDA-сборки без отдельной необходимости.
