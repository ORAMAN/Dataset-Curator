# Dataset Curator

Графическое приложение на Python/Tkinter для составления и редактирования датасета перед обучением LoRA/SDXL. Принцип работы: **каталог и все решения хранятся в SQLite; оригиналы изображений остаются на своих местах**. Изображения и EN-подписи копируются в конечную папку только после явного нажатия «Экспортировать набор».

## Возможности

- Фильтрация по разрешению, размеру лица, резкости и эстетической оценке.
- Поиск лиц через MediaPipe BlazeFace.
- Эстетическая оценка через aesthetic-predictor.
- Near-duplicate поиск по perceptual hash; найденные дубликаты можно только пометить в базе.
- Необязательные описания BLIP и классификация CLIP.
- Два отдельных текстовых поля на каждой карточке: описание на английском и перевод на русский.
- Редактирование описаний, статуса «выбрано/отклонено» и генерация описаний непосредственно из вкладок обзора.
- Вкладки «Выбранные» и «Отбракованные» с миниатюрами; отклонённые записи можно вернуть в выбранные без перемещения файла.
- SQLite-каталог на каждый набор: файл dataset_curator.sqlite3 в корне выбранной исходной папки.
- Явный экспорт выбранных изображений в новую папку: копируется изображение и создаётся TXT с английским описанием. Если доступны русские переводы, дополнительно формируется captions_ru.csv.
- Автосохранение настроек, категории CLIP, темы, размера и положения окна.
- Журнал, прогресс, остановка обработки и светлая/тёмная темы.

## Как устроена база

Для каждой фотографии SQLite хранит абсолютный путь, имя, статус, причину отклонения, размеры, результаты проверок, категорию CLIP, описание EN, перевод RU и ошибки. Статус и описания при ручной работе меняются в базе, но не меняют путь к фото и не создают TXT.

На первом открытии каталога приложение может импортировать сведения о файлах из старых подпапок selected, rejected, bed_size, blure, no_or_small_faces, moree_faces и duplicate. Это только чтение: старые файлы не перемещаются и не удаляются. Если рядом с такими фото есть TXT, текст используется как начальное английское описание в базе.

## Перевод на русский

По умолчанию используется **MyMemory Translation API** — бесплатный сервис машинного перевода с простым REST API, который не требует ключа для базового анонимного доступа:

- [Официальные лимиты MyMemory](https://mymemory.translated.net/doc/usagelimits.php)
- [Описание API MyMemory](https://mymemory.translated.net/doc/spec.php)

По опубликованным лимитам MyMemory, анонимный доступ ограничен примерно 5 000 символов в сутки. При указании действительного email в параметре de лимит может составлять до 50 000 символов в сутки. Лимиты и условия могут измениться.

На вкладке «AI-модели» можно включить/отключить автоматический перевод и при необходимости указать email для лимита. Текст английского описания отправляется MyMemory только для перевода; фотография не отправляется. Если перевод не удался, английское описание всё равно сохраняется в SQLite, а русское поле можно заполнить вручную или перевести позже.

Для полностью локального перевода можно самостоятельно поднять [LibreTranslate](https://docs.libretranslate.com/) на своём компьютере. В таком случае каталог можно дополнить выбором пользовательского URL сервера; публичный хостинг LibreTranslate не следует считать гарантированно бесплатным или неограниченным.

## Требования

- Windows 10/11 или другая ОС с Python 3.10+ и Tkinter.
- Рекомендуется Python 3.10–3.12 для совместимости AI-зависимостей; сверяйте версии библиотек с рабочим PyTorch.
- Установите зависимости командой: uv pip install --system -r requirements.txt

Если используете виртуальное окружение, активируйте его и выполните uv pip install -r requirements.txt без --system.

**PyTorch/CUDA устанавливайте отдельно.** Не переустанавливайте рабочую GPU-сборку только ради необязательных BLIP/CLIP. Для AI-подписей нужен transformers; для установки дополнительных AI-зависимостей используйте install_optional_ai.bat.

## Запуск и использование

Запустите start_dataset_curator.bat или командой python dataset_curator_gui.py.

1. Выберите исходную папку с изображениями в поле «Исходная папка».
2. Нажмите «СТАРТ», чтобы провести фильтрацию и записать статусы в SQLite, либо «📝 Только подписи», чтобы генерировать описания без предварительной фильтрации.
3. На вкладках «Выбранные» и «Отбракованные» редактируйте оба описания. Нажмите «Сохранить оба описания», чтобы записать их в SQLite.
4. Кнопки «Отклонить» и «Вернуть в выбранные» меняют статус только в базе.
5. Когда набор готов, нажмите «📦 Экспортировать набор» и выберите отдельную папку назначения.

Для экспорта копируются только записи со статусом «выбрано»/maybe и непустым английским описанием. Исходные изображения и база остаются без изменений. Имена файлов автоматически делаются уникальными, чтобы не перезаписать ранее экспортированные материалы. Русские переводы записываются в captions_ru.csv; обучающий sidecar TXT содержит английское описание.

## AI-модели

- **MediaPipe BlazeFace** — поиск лиц; если модель отсутствует, приложение может загрузить официальный blaze_face_short_range.tflite.
- **Aesthetic Predictor** — оценка эстетики; скор зависит от модели и не является объективной мерой качества.
- **BLIP** — генерация английского чернового описания. Можно задать префикс/trigger token.
- **CLIP** — сопоставление изображения с заданными текстовыми категориями. CLIP классифицирует, но не генерирует свободные подписи. При включении можно добавить выбранную категорию в английское описание.

Первое использование моделей Hugging Face может потребовать скачивания весов. Для приватных изображений учитывайте, что при включённом переводе текст описания передаётся внешнему сервису MyMemory.

## Файлы данных и конфиденциальность

- dataset_curator.sqlite3 — состояния, данные анализа и описания.
- dataset_curator_settings.json — настройки интерфейса; не предназначен для публикации.
- hf_token.txt — необязательный токен Hugging Face; он исключён из Git.
- Фотографии не перемещаются автоматически. Создание TXT и копирование изображений происходят только при финальном экспорте.

## Обновление

В ZIP-копии проекта запустите update.bat: он обновит код, сохраняя пользовательские настройки, SQLite-базу, локальные модели и файлы датасета. В Git-клоне обновлятор использует git fetch и fast-forward merge; при наличии локальных изменений сначала предложит отменить обновление или явно разрешить перезапись.

## Проверка

Начните с небольшой папки-копии. Сначала проверьте статусы и оба языка в SQLite, затем экспортируйте несколько изображений в пустую отдельную папку. Перед обучением проверьте английские описания вручную: автоматические подписи и перевод — черновики.
